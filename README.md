# Calculadora em Python

Projeto simples de calculadora desenvolvido para praticar lógica de programação e Python.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento de erro para divisão por zero)

## Como executar

1. Tenha o Python instalado
2. No terminal, digite: `python calculadora.py`
3. Escolha uma operação e digite os números

## Tecnologias

- Python 3
